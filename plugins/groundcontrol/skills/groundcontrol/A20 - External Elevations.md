# A20 - External Elevations   
**A201-A299**  
**A20.##**  
  
## EXTERNAL ELEVATIONS (1:100)  
**Subset: A201-A250** **or A20.##**  
- Grid lines  
- Finished floor level benchmarks  
- External wall systems nomination using materials, systems and finishes codes  
- Window dimensions horizontal and vertical  
- Windows vertical setting-out - offsets from finished floor level (Horizontal setting-out offsets from grids is already done in A10 - Floor and Roof Plans)  
- External doors vertical setting-out - offsets from finished floor level (Horizontal setting-out offsets from grids is already done in A10 - Floor and Roof Plans. External door hardware is described in A70 - Doors and Windows door schedule)  
- Glazing codes  
- Openable windows indication  
- ‘Enlarged area boxes’ referring to 1:50 elevations in **A25 subset**  
- Section references  
- Graphical differentiation between existing structure and new build  
- Movement/deflection joints  
  
## DETAILED SET-OUT ELEVATIONS, WITH ASSOCIATED PLANS AND SECTIONS (1:50)  
**Subsets: A251-A299** **or A25.##**  
Nested arrangement of elevation, associated plan(s) and section(s) at 1:50, showing typical and special conditions of the façade.    
Includes cladding, windows, curtain walling, shopfronts, roofing.    
Shows typical configurations and composite interface with roof, ceilings, floors and internal partitions.  
  
- Grid lines  
- Finished floor level benchmarks  
- External wall systems, materials and finishes codes (No internal finishes description - all internal finishes are documented in A60 - Internal Spaces (Room Layouts))  
- Section symbols referring to 1:5 plan and section details in A50 - Interface Details  
- ‘Enlarged area boxes’ referring to 1:5 plan details in A50 - Interface Details  
- Openable windows indication  
- Movement/deflection joints
