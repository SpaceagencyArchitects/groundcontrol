#groundcontrol/tips

* Include wet area setdown detail with dimension on room layouts or refer to detail
* Treatment to top of rammed earth walls
* List fixtures, fittings and finishes on room layout sheet (Keynotes, Description) with reference to spec or schedule
* Use generic labels for electrical items on arch plans (ceilings, room layouts) - eg LSP, DGPO, WL etc. Do not use full item code. Identify full code on electrical drawings only.

- floor types are finishes applied to structural subfloors. Don't include concrete slabs (unless the slab is the finish), joists or particleboard flooring that are part of the subfloor.

## Wall Types

- wall types exclude finishes, but include substrates. Eg. tiles, timber lining are finishes; plasterboard, render are substrates.
- A wall type exists to be reused. A unique condition is better handled as a location-specific annotation on the A10 plan or A50 detail, called out directly rather than through a type code.
  The practical test: ask for each variant — "if this cavity dimension changed, how many walls would I need to update?" If the answer is one, it's not a type, it's a one-off. Document it with a local note or a location-specific detail referenced directly from the plan.
  The exception worth noting: if a unique type exists because of a specific performance requirement (acoustic rating, fire rating) rather than just a dimensional accident, it may still warrant a type code so the requirement is clearly tied to that wall on the plan — even if it only appears once. In that case the type code is doing work beyond just identifying the build-up.
