# spA documentation // tips

* Include wet area setdown detail with dimension on room layouts or refer to detail
* Treatment to top of rammed earth walls
* List fixtures, fittings and finishes on room layout sheet (Keynotes, Description) with reference to spec or schedule
* Use generic labels for electrical items on arch plans (ceilings, room layouts) - eg LSP, DGPO, WL etc. Do not use full item code. Identify full code on electrical drawings only.

- floor types are finishes applied to structural subfloors. Don't include concrete slabs (unless the slab is the finish), joists or particleboard flooring that are part of the subfloor.

## Layouts

- ensure that each layout has
  - A scalebar representing the typical (most common) scale of drawings on the layout
  - A northpoint only if the drawing is a general arrangement or site plan. Do not show northpoints on sections, elevations, details, room layouts etc

### Drawings

- drawings placed on a layout should have a drawing title only if there are more than one drawing
- use the most current drawing title from the SpA Library
- Show ID only if the drawing is referenced by ID from another drawing (eg. details, sections, but not room layout plans, elevations etc). Show drawing name. Show scale only if the drawing is different to the main layout scale shown on the titleblock.

#### Naming conventions

- drawings placed on a layout should be numbered as follows:
  - Details 'by layout'. The order by which they are placed on the layout determines the order they are numbered
  - Sections 'custom' using the section letter (eg ID of 'A30/A Section A' should be 'A')

## Wall Types

- wall types exclude finishes, but include substrates. Eg. tiles, timber lining are finishes; plasterboard, render are substrates.
- A wall type exists to be reused. A unique condition is better handled as a location-specific annotation on the A10 plan or A50 detail, called out directly rather than through a type code.
  The practical test: ask for each variant — "if this cavity dimension changed, how many walls would I need to update?" If the answer is one, it's not a type, it's a one-off. Document it with a local note or a location-specific detail referenced directly from the plan.
  The exception worth noting: if a unique type exists because of a specific performance requirement (acoustic rating, fire rating) rather than just a dimensional accident, it may still warrant a type code so the requirement is clearly tied to that wall on the plan — even if it only appears once. In that case the type code is doing work beyond just identifying the build-up.

## Ceilings

- on ceiling plans tag ceiling height relative to FFL in each room
- no sections use a dimension line, do not use an elevation label (elevation labels need to be updated if FFL or ceiling level change. It is not obvious if they are showing the wrong level. Dimensions auto update or if they don't it is obvious that they are incorrect.)
- No GA ceilings (insufficient space for details) - use larger scale ceilings in A140 series, not A600 series

## Electrical

1. Show on ceiling plans, room layouts and room elevations. Not on electrical drawings.
2. Use electric symbols (no codes) for smoke detectors, motion sensors, emergency lights, back-of-house lights, light switches, GPOs - refer to electrical consultant's drawings for type.
3. Use symbols and specific code for architectural light fixtures
4. Show fixtures on ceiling plans, room elevations, etc
5. Produce electrical layouts only if no electrical consultant has been engaged
