# Introduction to Construction Documentation

## What Construction Documents Are

Construction documentation consists of two complementary parts: **drawings** and **specifications**.

> *"The drawings are the graphic and pictorial portions of the contract documents showing the design, location and dimensions of the work."*
> — AIA Document A201-2007

> *"The specifications are that portion of the contract documents consisting of the written requirements for materials, equipment, systems, standards and workmanship."*
> — AIA Document A201-2007, §1.1.6

The architectural drawing set is autonomous — it communicates a comprehensive representation of the future building without relying on verbal explanation. The specification deals with quality of materials and workmanship for items not fully shown on drawings.

The key distinction is this:

> **Drawings = architectural entities. Specifications = trade packages.**

An *architectural entity* (e.g. Reception, Main Entrance, External Wall) is a collection of building elements assembled in a predetermined configuration. We document architectural entities whole — we do not subdivide the drawing set to isolate information for individual trades.

---

## What the Drawing Set Concentrates On

Express design intent through three things:

- Dimensional setting-out of visible surfaces
- Definition of materials
- Definition of finishes

Everything else — structural design of fixings, internal profiling of extrusions, exact number of rubber blades in a gasket — belongs to specialist consultants, contractors, or construction managers. Do not assume responsibility for their work by over-specifying it.

Do not repeat other consultants' design information on our drawings.

## How to Draft

**Describe outcomes, not methods.** Tell contractors what the finished result must be, not how to achieve it.

**Draw technical diagrams, not pictures.** Sections and elevations do not need embellishment — linework, textures and fill are likely to change during documentation and add noise.

**Use nested arrangements.** At 1:50 and 1:25, combine plan, elevation and section on the same sheet. This efficiently communicates three-dimensional relationships.

**Draw only the special items.** Do not replicate standard construction details or information already provided by a proprietary system (e.g. a partition detail already well-drawn in the CSR Red Book does not need copying).

**Resolve details before you draw them.** Work out junctions on paper first and confirm the detail is needed before placing it in the drawing set.

**Label every detail as plan or section.** Never leave orientation ambiguous.

**3D drawings** are not generally used in construction documentation, but axonometric or isometric diagrams are justified where they clarify a complex condition shown elsewhere in plan, elevation and section.

For ArchiCAD setup — detail types, room layouts, workflows — refer to the ArchiCAD Workflows notes.

## How to Annotate

**Use the standard description pattern:**
Generic name → system/material code → finish description → finish code
e.g. *CLADDING EWS-3 PAINTED PT-4*

Only use abbreviations and codes that appear on the [[A00 - Introductory documents]] legend sheet.

**Write directly and simply.** One expression, one meaning. Avoid jargon.

**Minimum font sizes:** 2.0mm body text, 3.5mm detail titles — both measured at full print size, and legible when reduced to half size. All text must be horizontal or rotated 90° counterclockwise.

**Do not write notes such as "AS SPECIFIED", "AS SCHEDULED" or "REFER TO ENGINEER'S DETAILS".** Every component is either specified, scheduled, or documented by another consultant. Such notes are redundant and can mislead — a contractor may assume the work is covered elsewhere when it is not.

**Write in the active voice, using command form:**

| Avoid | Prefer |
|---|---|
| TO BE PAINTED TO MATCH EXISTING | PAINT TO MATCH EXISTING |
| HAND WASH BASINS SHOULD NOT BE REMOVED | DO NOT REMOVE HAND WASH BASINS |
| UTILISATION / ALIGNMENT / AVOIDANCE | USE / ALIGN / AVOID |
| WINDOW FRAMES TO BE REMOVED BY DEMOLITION CONTRACTOR | REMOVE WINDOW FRAMES AND MAKE GOOD OPENINGS |
| DO NOT INSTALL UNLESS APPROVED | INSTALL APPROVED SYSTEM |

## Tracking Revisions

- Cloud all changes on the drawing
- Add a revision triangle with revision number
- Write a brief, specific description in the revision column
- Never write "GENERAL REVISIONS" — it tells the contractor nothing
