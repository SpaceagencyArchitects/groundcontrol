# A16 - Lightning and Power Plans   
**A160-A179**   
**A16.##.## (LEVEL.SEQUENCE)**  
## Lighting and Power Setout Plans (1:100)  
Required only if not possible to show, code and dimension electrical items on plans, elevations and ceilings in [[A60 - Internal Spaces (Room Layouts)]]
  
Useful to brief electrical consultants.  
- Grid lines  
- Room names, room numbers  
- Lighting, power, communications, dry fire fixture symbols and codes  
- Setout dimensions only if not shown on other drawings
