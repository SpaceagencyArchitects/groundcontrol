# Windows   
## [[A00 - Introductory documents]] / Legend Sheet  
* Key to glazing codes - description of systems; reference to specification section   
  
## [[A10 - Floor and Roof Plans]]
* Unique identification tags for each window. Identification tag may vary from project to project. Options include:  
  - sequential numbers (eg. W01, W02, etc)  
  - room based number (eg. W"Zone Number".a)  
  - combination of the above and a window type identifier (eg. 'Window number" / "Window Type")  
* Horizontal setting-out of windows   
  
## [[A20 - External Elevations]]
* Unique identification tags for each window  
* Window dimensions (vertical)  
* Windows vertical dimensional setting-out - offsets from finished floor level  
Note: Every recess and facet of façade has to be elevated to show the full extent of the envelope and the window and door openings.  
  
## [[11F7F300-F61D-4213-85F1-F5B92EFD4206]]
* Window type elevations **1:25**  
* Line of heights control diagram **1:25**   
* Typical window frame details **1:5**  
* Window schedule key including window hardware schedule  
* Window schedule  
  - *Window schedule is used to describe hardware*.  
  - *If window geometry - sash sizes, etc. - is fully described in [[A20 - External Elevations]] or [[A60 - Internal Spaces (Room Layouts)]], make reference to relevant drawings by writing a note in schedule ‘FOR DETAILS REFER' TO DRAWING A20.xx’*. *There is no need to repeat the information in the schedule.*  
  
  
## [[A50 - Interface Details]]  
* Special window frame/sill/head conditions   
  
## [[Z - Specifications]]  
* glazing specificaion  
* Framing specification
