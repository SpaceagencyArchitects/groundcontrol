## [[A00 - Introductory documents]] / Legend Sheet  
* Key - description of systems and materials; reference to specification section   
  
## [[A14 - Reflected Ceiling Plans]] 
* Systems and materials codes  
* Ceiling heights relative to finished floor level of room  
* Ceiling fixtures (electrical, mechanical)  
  
## [[A80 - Schedules]] 
*Covers most of the areas by allocating finishes code. For more complex areas instead of trying to code it, write a note in schedule ‘FOR DETAILS REFER TO DRAWING A60.##’*  
* Key - description of finishes codes; reference to specification section  
* Create columns in room finishes schedule: CEILING | Material | Finish | Bulkhead | Material | Finish  
* Reference complex areas which can not be scheduled to **1:50** reflected ceiling plans in A60 - Internal Spaces (Room Layouts)  
  
## [[A60 - Internal Spaces (Room Layouts)]] / Reflected Ceiling Plans (1:50)  
*Needed only if graphically too heavy in A14 - Reflected Ceiling Plans. If required show ‘enlarged area boxes’ referring to an enlarged area in A14 - Reflected Ceiling Plans. Do not repeat descriptions.*  
* Describe various areas of different ceiling finishes using finishes codes  
* Indicate finish to vertical surfaces e.g. bulkheads  
* Make reference to **1:5** details in A50 - Interface Details  
  
## [[A50 - Interface Details]]  
* *(generic)* ceiling-to-ceiling details  
* *(location specific)* ceiling interface with external wall **1:5**  
* *(location specific)* ceiling interface with partitions **1:5**
