# Paint Finishes  
## [[Z - Specifications]]
- Full description of each paint system: product type, sheen level, number of coats, and surface preparation requirements.
- Each system is assigned a PT code (PT1, PT2…). The same PT code applies regardless of which substrate or element it is used on — do not create separate PT codes for walls, ceilings, and trims if the same system applies to all.
- The PT code is a specification cross-reference. It appears on drawings and schedules only as a pointer back to the relevant spec clause.

## [[A80 - Schedules]] / Colour Schedule
- Standalone document listing every colour used on the project.
- Each colour is assigned a C code (C1, C2…) with manufacturer reference and full colour description.
- The Colour Schedule is issued and revised independently of the room schedule and specification — colour decisions typically lag behind paint system decisions and change more frequently during the project.
- C codes are referenced on the A00 Legend Sheet.

## [[A00 - Introductory documents]] / Legend Sheet
- PT codes listed with a reference to the relevant Z Specification section.
- C codes listed with a reference to the A80 Colour Schedule.
- Do not describe the full paint system or colour on the legend sheet — the legend sheet carries the code and a pointer only.

## [[A80 - Schedules]] / Room Schedule and [[A60 - Internal Spaces (Room Layouts)]]
- Painted surfaces annotated with the combined code: PT/C — e.g. PT1/C4 = paint system PT1 in colour C4.
- Where all surfaces in a room share the same paint system, a single note is cleaner than repeating the PT code in every cell.
- Complex areas that cannot be adequately described in the room schedule: note 'FOR DETAILS REFER TO DRAWING A60.##' and carry the combined codes on the A60 internal elevations.

## Frame and joinery finishes
- **Factory-applied finishes** (powder coat, anodising, factory paint): described in the A70 Door and Window Schedule and the Z Specification. The fabricator reads this — the painter does not.
- **Site-applied paint to timber frames, jambs, and architraves**: treat the same as any other painted surface. Carry in the A80 Room Schedule or A60 elevations. The Z Specification covers site-applied paint to all joinery timber as a single clause.
- Do not put site-applied paint information only in the A70 schedule — the painter will not find it there.
